## About the Book

*Applied Quantitative Methods in Technology Foresight: AI-Enhanced Approaches* addresses the critical challenge of integrating traditional quantitative methods with emerging artificial intelligence techniques in technology foresight. As technological change accelerates and becomes more complex, conventional analytical approaches alone are insufficient for accurate technology assessment and prediction. This graduate-level reference work presents a novel framework that combines established statistical methods with cutting-edge AI applications.

The book makes three primary contributions to the field:

- A structured approach to integrating traditional quantitative methods (bibliometrics, patent analytics) with modern AI/ML techniques, offering a comprehensive methodology for enhanced technology foresight.
- Practical implementation guidance through detailed Python and R code examples, addressing the significant gap between theoretical understanding and practical application.
- A unique hybrid approach to technology emergence detection, combining multiple analytical methods for improved accuracy and reliability.

**Keywords:** technology foresight · quantitative methods · artificial intelligence · machine learning · patent analytics · bibliometrics · text mining · predictive analytics · deep learning · technology assessment · innovation analytics · data science · strategic planning · technology intelligence · computational foresight

## Repository Structure

This repository hosts the source code, datasets, and supplementary materials for all chapters of the book. Each chapter has a dedicated folder following the naming convention `chXX`, where `XX` is the zero-padded chapter number. Inside each folder, authors have provided a `README.md` with instructions on how to use the code, along with the relevant scripts, notebooks, and data files.

```
/
├── ch01/   Introduction to Quantitative Technology Foresight
├── ch02/   Fundamentals of Data in Technology Foresight
├── ch03/   Statistical Foundations for Technology Analysis
├── ch04/   Bibliometric Analysis in Technology Foresight
├── ch05/   Patent Analytics and Technology Mining
├── ch06/   Multivariate Analysis for Technology Assessment
├── ch07/   Machine Learning in Technology Forecasting
├── ch08/   Deep Learning Applications in Foresight
├── ch09/   Text Mining and Natural Language Processing
├── ch10/   Hybrid Methods and Foresight Frameworks
├── ch11/   Visualization and Communication
├── ch12/   Tools and Software Implementation
├── ch13/   Emerging Technology Detection
├── ch14/   Strategic Technology Planning
└── ch15/   Future Directions and Evaluation Methods
```

To get started with a specific chapter, navigate to its folder and consult the `README.md` file for dependencies, installation instructions, and usage guidance.

## How to Use This Repository

1. **Clone the repository:**
   ```bash
   git clone https://github.com/sn-code-inside/applied-quantitative-methods-in-technology-foresight.git
   ```

2. **Navigate to the chapter of interest:**
   ```bash
   cd chXX
   ```

3. **Follow the chapter-specific instructions** in the `README.md` file inside each folder. Each chapter README documents required dependencies, environment setup, data sources, and execution instructions.

4. **Install dependencies** as specified per chapter. Most chapters use Python or R; refer to each chapter's README for exact version requirements.

---

## General Requirements

While each chapter specifies its own dependencies, the following are commonly used across the book:

- Python 3.8+
- R 4.0+
- Jupyter Notebook / JupyterLab
- Common Python libraries: `pandas`, `numpy`, `scikit-learn`, `matplotlib`, `seaborn`, `networkx`
- Common R packages: `tidyverse`, `bibliometrix`, `igraph`

For chapter-specific requirements, always refer to the individual chapter README.

## Data Sources

The analyses in this book draw primarily on open-access data sources to ensure full reproducibility:

- [Lens.org](https://www.lens.org) — patent and scholarly data
- [OpenAlex](https://openalex.org) — open scholarly metadata
- [Web of Science / Scopus](https://www.webofscience.com) — bibliometric data (institutional access may be required; consult your institution's library)

Where proprietary data has been used, the relevant chapter README provides guidance on how to obtain equivalent datasets.
