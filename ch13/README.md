# Chapter 13: Emerging Technology Detection

## Overview

> **Authors:**
> - M. Sc. Bruno Abreu Santos Catão (Oswaldo Cruz Foundation – Bio-Manguinhos)
> - Prof. Dr. Beatriz de Castro Fialho (Oswaldo Cruz Foundation – Bio-Manguinhos)
> - Prof. Dr. Eduardo Krempser (Oswaldo Cruz Foundation – Bio-Manguinhos)

This chapter addresses the critical challenge of transitioning theoretical weak signal detection into continuous, practical vigilance using advanced computational techniques such as Artificial Intelligence (AI) and Machine Learning (ML). The methodology is grounded in strategic management theory and validated through a comprehensive case study on the RNA technology trajectory from 1950 to 2010.

The initial detection phase successfully processed over 1.2 million documents and reduced approximately 36 million terms to a manageable set of weak signal candidates using traditional quantitative techniques (K-means clustering, Burst Detection). Building upon that foundation, the study introduces Word Embeddings (Word2Vec) to analyze the evolution and validate the semantic relevance of these signals — shifting from simple frequency analysis to semantic validation to overcome the "Curation Bottleneck."

The exercises and scripts provided in this repository replicate the core sequence of the quantitative funnel for weak signal detection and semantic vigilance, as detailed in the Catão (2025) study.

## Usage

Scripts should be executed **from the `Chapter_13/` directory** so that relative paths resolve correctly.

### Core Exercises (Book Sequence)

Run the exercises in order to reproduce the quantitative funnel:

```bash
# Exercise 5.1 – Data Preparation & Normalization
python "5.1_Data Preparation and Normalization.py"

# Exercise 5.2 – Specificity Hierarchy & Noise Reduction
python "5.2_Hierarchizing Specificity and Reducing.py"

# Exercise 5.3 – TF-IDF + K-means Clustering
python "5.3_Conceptual Clustering and Thematic Grouping.py"

# Exercise 5.4 – Burst Detection (Emergence & Significant Growth)
python "5.4_Identifying Technological Emergence.py"

# Tutorial 6 – Word2Vec Training, Semantic Validation & Vigilance
python "6_Word Embedding Models for Weak Signal Detection.py"
```

### Advanced / Expert Pipeline (Beyond the Book)

These scripts extend the analysis with temporal Word2Vec models and expert-curated candidate ranking. Run them **strictly in this order**:

```bash
# Step 1 – Generate all Parquet trajectories from raw triennial JSONs
python expert_1_out_of_book_preparation.py

# Step 2 – Calculate Burst Scores for expert-curated candidates
python expert_2_out_of_book.py

# Step 3 – Generate tokenized Master Corpus
python expert_3_out_of_book_master_corpus.py

# Step 4 – Train temporal Word2Vec models (Early vs. Late)
python expert_4_out_of_book_training.py

# Step 5 – Semantic Displacement ranking (final output)
python expert_5_out_of_book_comparison.py
```

## Data Sources

### Primary Corpus — `data/advanced/documentos_com_full_text.json`

The full-text bibliometric corpus was constructed following the systematic search strategy described in **Appendix D** of the originating master's dissertation (Catão, 2025). The original study collected data from **four independent scientific databases**, applying the Boolean keyword groupings detailed below to each source individually.

- **Search scope:** Messenger RNA (mRNA) technology and its bio-pharmaceutical applications
- **Temporal coverage:** 1950–2010 (60 years)
- **Sampling strategy:** Up to 500 documents per year, sorted by relevance as ranked by each database's search engine
- **Extraction date:** 2024

#### Original Collection Volume

| Metric | Dimensions | Scopus™ | Web of Science™ | PubMed™ | **Total** |
|--------|-----------|---------|-----------------|---------|-----------|
| Complete retrieval | 108,055 | 751,681 | 5,001 | 343,057 | **1,205,100** |
| After deduplication (per database) | 76,015 | 732,193 | 2,591 | 167,697 | **978,496** |

After cross-database deduplication, consolidation, and N-gram extraction, approximately **36 million unique N-gram terms** were derived from the corpus.

- **License:** Each database has its own terms of use. Scopus™ data is governed by [Elsevier's Terms](https://www.elsevier.com/legal/elsevier-website-terms-and-conditions); Web of Science™ by [Clarivate's Terms](https://clarivate.com/legal/terms-of-use/); PubMed™ data is publicly available via [NLM's Terms](https://www.nlm.nih.gov/databases/download/terms_and_conditions.html); Dimensions data is accessible under [Digital Science's Terms](https://www.dimensions.ai/terms). Users should consult the respective license agreements before commercial use.

> **Simplified reproduction path:** Readers who do not have institutional access to all four databases may use **[Lens.org](https://www.lens.org)** as a single open-access aggregator that indexes records from PubMed, Crossref, Microsoft Academic, CORE, and other providers. Lens.org data is available under the [Creative Commons Attribution 4.0 (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/) license. While the resulting corpus will not be identical to the original, it provides a practical approximation for reproducing the exercises in this chapter.

#### Cumulative Search Queries

The six searches were constructed as cumulative Boolean intersections of the groupings above:

| Search | Logic | Description |
|--------|-------|-------------|
| **S1** | A | Broad technical terms for the technology |
| **S2** | A AND B | Specific technical terms |
| **S3** | A AND B AND C | Terms associated with the RNA molecule |
| **S4** | A AND B AND C AND D | Terms related to potential applications and processes |
| **S5** | A AND B AND C AND D AND E | Vaccine-related terms |
| **S6** | A AND B AND C AND D AND F | Technology foresight and weak signal terms |

#### Reproducing the Corpus

To reconstruct `data/advanced/documentos_com_full_text.json` from scratch:

1. Access [Lens.org](https://www.lens.org) and execute the Boolean queries described above.
2. For each year from 1950 to 2010, retrieve up to **500 documents** sorted by the platform's relevance ranking.
3. Export the results including the **full text** and **publication year** fields.
4. Consolidate all annual exports into a single JSON file where each record contains at least the keys `document_full_text` (string) and `publication_year` (integer).

> **Note:** The resulting file is approximately 450 MB and exceeds GitHub's per-file size limit. It is therefore **not included** in this repository. Readers must reconstruct it following the procedure above or contact the authors for access.

For full methodological details, see **Appendix D — "Aplicação do Método no Estudo de Caso: RNAm"** in:
